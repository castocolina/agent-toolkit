# Compact instruction-file examples

Root file example:

```markdown
# Project
One sentence describing the repository.

## Essential commands
- Test: `...`
- Build: `...`

## Conditional guidance
- Read `.claude/testing.md` before changing or writing tests.
- Read `.claude/typescript.md` before editing TypeScript code.
```

Linked topic files should contain only actionable rules, plus scope and exceptions that determine when each rule applies. Use concrete paths and explicit read conditions rather than generic Overview/Good/Avoid sections.
