# Missing Ref

Rotate a billing key in three steps. Always read `references/rotation-runbook.md` first; it holds the exact order of revoke and issue calls and the 15-minute grace window.

1. Run `billing-keys list --expiring` and pick the key.
2. Follow the runbook for the revoke and issue order.
3. Run `billing-keys verify <new-key>`.
