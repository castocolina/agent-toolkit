# a11y

## Success criteria to cite

Figures read from WCAG 2.2 on 2026-10-30. Cite the SC id in the evidence or fix cell.

| topic | fail line | SC, level |
|-------|-----------|-----------|
| text contrast | under 4.5:1; large text (18 pt, or 14 pt bold) under 3:1 | 1.4.3 AA |
| non-text contrast | input borders, icons, state indicators, focus rings under 3:1 against adjacent colors | 1.4.11 AA |
| label in name | accessible name does not contain the visible text | 2.5.3 A |
| name and role | not programmatically determinable | 4.1.2 A |
| keyboard | an action not operable from the keyboard | 2.1.1 A |
| target size | pointer target under 24 by 24 CSS px, outside the exceptions below | 2.5.8 AA |
| reflow | two-dimensional scrolling at 320 CSS px | 1.4.10 AA |

## Decisions

- 24 versus 44: 24 by 24 CSS px is the AA fail line (2.5.8). 44 by 44 is AAA (2.5.5) and the Apple HIG hit region (44 pt); web.dev suggests about 48 px with about 8 px between targets. Design to 44 to 48, fail only under 24.
- 2.5.8 exceptions, each a pass: a 24 px circle centred on the target does not overlap another target or its circle (spacing); an equivalent control of passing size exists; the target is inline in a sentence; the user agent sizes it; the size is essential.
- Name source order: visible text; `aria-labelledby` when visible text exists elsewhere; `aria-label` only for icon-only controls. Never both on one element; `aria-label` overrides `alt` and `<label>` (MDN).
- An input border is the non-text contrast case people miss: when the field has no fill, the border is what identifies it, so it needs 3:1. `#ccc` on white is about 1.6:1 and fails.

## Gotchas

- `aria-label="Confirm"` on a button that shows "Save" fails 2.5.3: speech users say the word they see, and it does not match the name.
- An icon inside a named button gets `aria-hidden="true"`, as in MDN's `aria-label` example, so only the label is announced.

## Fix pattern

```tsx
<IconButton aria-label="Delete order" onClick={onDelete}><DeleteIcon /></IconButton>
```

```css
.icon-btn { min-width: 2.75rem; min-height: 2.75rem; display: inline-grid; place-items: center; }
```
