## Review Focus

1. Stage 1 changes the pinned spec and stage 2 judges against the old pin → stage 2 starts from the pin stage 1 produced, or from the committed one when stage 1 made no change. Pinned in plan 11 Task 3 (B3); checked in Task 1.
2. A new artifact kind widens what a model can edit → the scope check allowlist names kinds explicitly and the fixer may only touch the artifacts the decision lists. Pinned in Task 2.
3. The matrix explodes in cost, or the same artifacts are picked every run → a per-run cap `AUDIT_MAX_ARTIFACTS` (default 10) on the rotation and a cursor in the audit state that only `state` advances (gating table, row `state`), so it moves by the cap exactly when `state` writes. The cap never bounds `detect`'s own full set (spec, judge or state change, `force`; plan 11 cuts `re_review=no`). Pinned in Task 2.
4. The model-validity pass edits rules automatically → it only produces proposals in the PR body. Pinned in Task 2.
5. The review job approves its own judge change → a PR that changes `skills/skill-judge/**` always requires a human, regardless of `AUDIT_ON_POSITIVE`. Pinned in Task 3.
