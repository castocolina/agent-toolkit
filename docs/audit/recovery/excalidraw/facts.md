## Defect found while checking (not a stale fact)

`skills/excalidraw/scripts/scene.py` line 197 creates ids with `secrets.token_urlsafe(15)`, whose alphabet includes `-`. About 1 id in 64 starts with `-`, and `argparse` reads `--allow -abc...` (and `--remove`, `--relabel`, `--connect` values that are such an id) as an option, so the call exits 2. This is the cause of the flaky `test_edit_leaves_untouched_elements_and_top_level_identical`: its last step passes the created ids as `--allow <id>` (about 3 new ids per run, measured 7 failures in 200 runs, always `2 != 0` at test_scene.py line 145). SKILL.md also tells users to pass ids with `--allow ID`, so real use hits it. Fix options for the restore dispatch: make `new_id` never start with `-` (retry or prefix), or have the docs and tests pass `--allow=ID`.
