# Facts: mermaid-diagrams (checked 2026-11-13, installed mmdc 12.2.0)

Method: syntax claims were checked against the official Mermaid docs (https://mermaid.js.org, fetched 2026-11-13) and by running the installed `mmdc` 12.2.0 on probe files (`mmdc --version` prints 12.2.0; its `node_modules/mermaid` is 12.3.0, and `pnpm view @mermaid-js/mermaid-cli dependencies.mermaid` returns `^12.2.0`). `mmdc` exits 1 on a parse or render error, so a probe's exit code is the evidence for "parses" and "fails". Probe sources and results live in `tmp/mermaid-diagrams-probe/` of the worktree. The mermaid-cli README was read with `gh api repos/mermaid-js/mermaid-cli/readme`. Mermaid's own latest release is `mermaid@12.3.0` (2026-11-03, `gh api repos/mermaid-js/mermaid/releases`). Where docs and tool output could differ the tool output is the evidence. `npm` is banned on this machine, so nothing was installed.

Headline finding: the current files assume Mermaid 11 defaults. Mermaid 12.0.0 (breaking release) bundles ELK as the default layout engine and makes `redux-color` and the `neo` look the defaults for flowchart, class, ER, sequence, state and four newer types. An unpinned `npx -y @mermaid-js/mermaid-cli` now resolves Mermaid 12. SKILL.md, README and the restored config sections must say so (see the rows on the CLI dependency, `layout: elk`, the Mermaid 12.0.0 defaults and the README theme, layout and look lines).
